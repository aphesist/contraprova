What am I looking at?

Every panel is a projection of one hash-chained event log, computed in Python and exported as JSON. The timeline replays the log: everything shows the state as of event N.

Attempts: one point per arm × task, including fork re-runs, labelled from each fork's role (D:control = same cheap model again, D:treatment = escalated; a second control at the same fork point is D:control-2). Fork re-runs are fork events and fork outcomes in the log, never arms. Position is a deterministic PCA layout of token, request and gate counts — not semantic meaning. Colour = one logged fact; size = cost. Click a point for its event trail.

Cost vs solve rate: per arm, with 95% Wilson intervals; dashed line = Pareto frontier over arms A–D. Hollow = fork re-runs, which cover only failed-once tasks and are not comparable with the arms. Switch price tables to re-price the same history.
