what am i looking at?

every figure is a projection of one hash-chained event log, computed in python and exported as json. the timeline replays the log: everything shows the state as of event n.

attempts: one point per arm × task, including fork re-runs, labelled from each fork's role (D:control = the same cheap model again, D:treatment = escalated; a second control at the same fork point is D:control-2). fork re-runs are fork events and fork outcomes in the log, never arms. position is a deterministic pca layout of token, request and gate counts, not semantic meaning. colour = one logged fact; size = cost. click a point for its event trail.

cost against solve rate: per arm, with 95% wilson intervals as stippled bands; the ink step is the pareto frontier over arms A–D. hollow = fork re-runs, which cover only failed-once tasks and are not comparable with the arms. switch price tables to re-price the same history.
